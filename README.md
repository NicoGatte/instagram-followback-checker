# Instagram Followback Checker

Tool semplice per vedere chi non ti segue su Instagram direttamente dal browser.

## Features
- Nessun login richiesto
- Tutto locale nel browser
- Ricerca utenti
- UI responsive
- Link diretti ai profili Instagram

## Come usare
1. Apri Instagram nel browser
2. Apri la console (F12)
3. Incolla lo script
4. Copia il JSON generato
5. Incollalo nel sito

## Tecnologie
- HTML
- CSS
- JavaScript

## Privacy
Nessun dato viene inviato a server esterni.
Tutto viene elaborato localmente nel browser.
